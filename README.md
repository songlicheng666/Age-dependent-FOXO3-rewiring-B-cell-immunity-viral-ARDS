## Overview

This repository contains all analysis scripts associated with the manuscript investigating age-dependent B-cell immune dysregulation in virus-associated ARDS. The study integrates three complementary multi-omics platforms:

1. **Plasma proteomics** (DIA-MS, n = 67 samples across four groups) — identifying age-divergent humoral immune programs and a FOXO3-centered prognostic protein panel
2. **Peripheral blood scRNA-seq + BCR V(D)J sequencing** (10x Genomics 5′, n = 43 donors) — resolving B-cell state remodeling and clonal dynamics at single-cell resolution
3. **Lung spatial transcriptomics + BALF scRNA-seq** (continuity analysis from GSE223793 / PRJCA042363) — mapping FOXO3-driven B-cell niches in injured lung tissue

The study spans four clinical groups: pediatric ARDS (PARDS, n = 20 for proteomics; n = 9 for scRNA-seq), adult ARDS (AARDS, n = 20; n = 9), pediatric controls (n = 13), and healthy adult controls (n = 14).

## Module Descriptions

### `01_proteomics/` — Plasma Proteomics (DIA-MS)

All scripts operate on the plasma proteome quantification matrix (`ALL_sample.final_matrix.csv` / `.xlsx`) generated by the iProteome cloud platform. Protein abundances are expressed as fraction-of-total (FOT × 10⁵) and log₂-transformed for statistical analyses. The four sample groups are encoded as:

| Code | Description |
|------|-------------|
| `AA` | Adult ARDS (AARDS) |
| `AC` | Adult healthy controls |
| `CA` / `CA1` / `CA2` | Pediatric ARDS (PARDS, acute T1 / outcome T2) |
| `CC` | Pediatric healthy controls |

| Script | Function | Paper section |
|--------|----------|---------------|
| `01_QC_protein_count_per_sample.R` | Per-sample protein detection count, outlier flagging (3σ), group-level summary statistics | Supplementary Methods 3 — QC |
| `02_PCA_visualization.R` | PCA on standardized protein matrix, ellipse-annotated scatter plot | Fig. 2 / Supplementary Fig. 2 |
| `03_differential_protein_analysis.R` | Two-group DEP analysis (Welch t-test / Mann–Whitney U), Hedges' g / Cliff's delta, BH-FDR correction; linear regression with clinical covariates | Supplementary Methods 3 — DEP |
| `04_heatmap_control_DEPs.R` | Heatmap of significant DEPs between pediatric and adult controls (CC vs AC) | Fig. 2a |
| `05_heatmap_immunoglobulin_comparison.R` | Heatmap of immunoglobulin family proteins with directional annotation (AC_UP / CC_UP) | Supplementary Fig. 2d / f |
| `06_WGCNA_module_analysis.R` | WGCNA soft-threshold selection, module detection, module–trait correlation (biweight midcorrelation), hub protein identification | Fig. 2e–f / Supplementary Fig. 3 |
| `07_ARDS_protein_expression_boxplot.R` | Protein-level expression visualization for candidate markers (FOXO3, TLR7, IL6ST, etc.) across all five groups with statistical annotations | Fig. 2 / Supplementary Fig. 2 |
| `08_prognostic_panel_ROC.R` | Logistic regression, ROC curve generation (pROC / DeLong method), AUC comparison for single proteins and composite panels | Supplementary Fig. 3c |

### `02_scRNAseq_BCR/` — Single-Cell RNA-seq and BCR Repertoire

Scripts in this module operate on Seurat objects produced by Cell Ranger → Seurat preprocessing (GRCh38 reference, Harmony batch correction). The B-cell-focused Seurat object is referred to as `CountsSeuratB_umap_J`. BCR data are stored in the `scBCR_RNA_PB` object processed by scRepertoire.

Group labels used in single-cell metadata:

| Code | Description |
|------|-------------|
| `CA` | Pediatric ARDS (combined T1 + T2) |
| `AA` | Adult ARDS |
| `CC` | Pediatric controls |
| `AC` | Adult controls |

| Script | Function | Paper section |
|--------|----------|---------------|
| `01_cell_proportion_calculation.R` | Cell-type proportion calculation across four groups (major lineages and B-cell subtypes), Wilcoxon tests with Bonferroni correction, boxplot visualization | Fig. 1b–e / Fig. 3b–d |
| `02_BCR_clonotype_matrix_extraction.R` | Clonotype abundance matrix construction, isotype proportion per sample, clonal homeostasis summary; integration with Seurat cell-state annotations | Fig. 4 / Supplementary Fig. 5–6 |
| `03_GO_enrichment_bubble_plot.R` | Multi-cluster GO enrichment bubble plot from Metascape/clusterProfiler output (gene ratio × −log₁₀ p-value × gene count) | Supplementary Fig. 4d / 5e |
| `04_SCENIC_transcription_factor_analysis.R` | SCENIC regulon inference (GENIE3 → RcisTarget → AUCell), FOXO3 regulon activity scoring, age-group comparison of regulon activity | Fig. 5d–e / Supplementary Fig. related |

---

### `03_spatial_transcriptomics/` — Spatial Transcriptomics (Continuity Analysis)

These scripts perform continuity analyses on the previously published pediatric ARDS spatial transcriptomic dataset (GSE223793 / PRJCA042363). The integrated Visium Seurat object is `Spatial_integrated`. Deconvolution weights (NNLS via RcppML; RCTD via spacexr) are stored in the `celltypeprops` assay.

| Script | Function | Paper section |
|--------|----------|---------------|
| `01_gene_set_scoring_spatial.R` | AddModuleScore-based scoring of apoptosis, inflammation, IFN-α, and IFN-γ gene sets at the spot level; SpatialFeaturePlot visualization | Fig. 6h–k / Supplementary Fig. 8 |
| `02_spatial_Bcell_niche_analysis.R` | B-cell spot identification (NNLS/RCTD weights or marker-based), FOXO3 module scoring, region-level enrichment, spatial correlation with apoptosis/inflammation scores, LIVE vs DEATH comparison | Fig. 6h–l / Supplementary Fig. 8e–h |

## Software Dependencies

All analyses were performed in **R ≥ 4.2**. Key packages are listed below by module.

### Proteomics
```r
# Core analysis
library(WGCNA)        # v1.72  — co-expression network analysis
library(DESeq2)       # v1.38  — variance-stabilizing transformation
library(pROC)         # v1.18  — ROC curve and DeLong AUC
library(pheatmap)     # v1.0.12 — heatmap visualization

# Visualization
library(ggplot2)      # v3.4
library(ggrepel)      # v0.9
library(ggforce)      # v0.4   — ellipse annotation in PCA

# Data manipulation
library(dplyr)        # v1.1
library(tidyr)        # v1.3
library(readxl)       # v1.4
```

### scRNA-seq and BCR
```r
library(Seurat)       # v4.3 / v5.x — single-cell analysis framework
library(harmony)      # v0.1        — batch correction
library(scRepertoire) # v1.8        — BCR repertoire analysis
library(SHazaM)       # v1.1        — somatic hypermutation analysis
library(Monocle3)     # v1.2        — pseudotime trajectory inference
library(SCENIC)       # v1.3        — transcription factor regulon analysis
library(GENIE3)       # v1.18       — gene regulatory network inference
library(AUCell)       # v1.18       — regulon activity scoring
library(RcisTarget)   # v1.18       — motif enrichment
library(fgsea)        # v1.22       — fast GSEA
library(msigdbr)      # v7.5        — MSigDB gene sets

# Visualization and statistics
library(ggpubr)       # v0.6
library(rstatix)      # v0.7
```

### Spatial Transcriptomics
```r
library(Seurat)       # v4.3 / v5.x
library(UCell)        # v2.0   — robust module scoring
library(patchwork)    # v1.1   — multi-panel figure assembly
library(fgsea)        # v1.22
library(msigdbr)      # v7.5
```

## Sample Group Coding Reference

The proteomics matrix uses sample IDs (`S1`–`S108`, `BF1`–`BF5`, `L`-prefixed) that map to the following experimental groups. The single-cell metadata uses text labels (`childcontrol`, `adultcontrol`, `childARDS_T1`, `adultARDS_T1`, etc.) stored in the `group` and `group1` metadata columns of the Seurat object.

| Proteomics code | Single-cell label | Clinical group |
|-----------------|-------------------|----------------|
| `AA` | `adultARDS_T1` / `AA` | Adult ARDS (AARDS) |
| `AC` | `adultcontrol` / `AC` | Healthy adult controls |
| `CA` / `CA1` | `childARDS_T1` / `CA` | Pediatric ARDS T1 (acute phase) |
| `CA2` | `childARDS_T2` | Pediatric ARDS T2 (outcome phase) |
| `CC` | `childcontrol` / `CC` | Pediatric healthy controls |
